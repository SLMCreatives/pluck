## Architecture

**Peek** is a mobile-first portfolio builder. Users fill out a wizard, go live instantly on Free, then upgrade for custom slugs and advanced features.

### Data model (`types/portfolio.ts`)
- `PortfolioData` — top-level: name, title, bio, profile image, phone, showPhone, social links, tabs
- `Tab` — named section (e.g. "Work") containing an ordered list of `ContentBlock`
- `ContentBlock` — discriminated union: `GalleryBlock | VideoBlock | ExperienceBlock`

### Wizard flow (`app/startup/page.tsx`)
State machine: `onboarding → social → tabs → blocks → block-form → preview`. All state is local React state. Each step is a component in `components/wizard/`. The preview step no longer has a slug input — the slug is auto-generated by `saveProfile` on the backend.

### Backend (Convex)
- `NEXT_PUBLIC_CONVEX_URL` env var required — set in `.env.local`
- `ConvexClientProvider` wraps the app at the root layout
- Run `npx convex dev` (alongside `pnpm dev`) to sync schema and functions

### Auth (Convex Auth)
- `@convex-dev/auth` with Password provider
- `middleware.ts` — protects `/startup` and `/dashboard`, redirects unauthenticated users to `/auth`
- `app/auth/page.tsx` — combined sign in / sign up page
- Requires `JWT_PRIVATE_KEY` and `SITE_URL` set in the Convex dashboard env vars

### Styling
- Tailwind CSS v4 with `@tailwindcss/postcss`
- shadcn/ui component library (Radix UI primitives)
- Dark theme throughout; zinc/indigo/emerald palette

## Pricing Strategy

| Tier    | Price          | Key limits / features |
|---------|----------------|----------------------|
| Free    | RM 0 forever   | 3 blocks, 3 projects (tabs), 6 images total, auto-generated URL, Peek badge, basic lead capture, no analytics, basic themes |
| Publish | RM 19/mo (pay-as-you-go: 1 / 3 / 6 / 12 months) | Unlimited blocks / projects / images, custom username, no badge, enhanced lead capture, basic analytics (view count), premium themes |
| Pro     | Coming soon    | Custom domain, advanced analytics, multiple portfolios, priority support |

### Tier limits (enforced in frontend wizard + Convex backend)
```
FREE_LIMITS  = { tabs: 3, blocks: 3, images: 6 }
```
Source of truth: `lib/limits.ts`. Limits are enforced in:
- `StepTabs` — disables "Add tab" / "Add block" buttons when at limit
- `GalleryForm` — caps image upload to remaining slots
- `convex/profiles.ts` (`saveProfile`, `updateProfile`) — server-side validation rejects over-limit saves

### User flow

1. **Sign up → Wizard → Go live (Free)**
   - User completes wizard and clicks "Publish My Portfolio".
   - `saveProfile` auto-generates a slug (e.g. `a7x92k`), inserts with `published: true`, `tier: "free"`.
   - Redirect to `/dashboard`. Profile is immediately live at `peek.com.my/a7x92k`.
   - Dashboard shows the auto-generated URL and an Upgrade CTA.

2. **Upgrade to Publish**
   - User clicks Upgrade on the dashboard or visits `/pricing`.
   - Pricing page shows a duration selector (1, 3, 6, or 12 months) and the total cost.
   - Calls `createSubscriptionCheckout` action with `months`.
   - Action creates a Stripe **one-time payment** checkout (`mode: "payment"`) with dynamic price (MYR), supports FPX.
   - Stripe redirects to `/startup/subscribed?tier=publish` on success.
   - Stripe webhook `checkout.session.completed` → `activateSubscription` sets `tier`, `stripeCustomerId`, `subscriptionExpiresAt`.
   - `/startup/subscribed` polls `getMyProfile` then redirects to `/dashboard`.

3. **Subscription expiry**
   - `subscriptionExpiresAt` is stored as a Unix timestamp (ms).
   - Convex cron in `convex/crons.ts` runs every 6 hours → `expireSubscriptions` unpublishes profiles past their expiry and resets them to `tier: "free"`.
   - Dashboard shows expiry date and a "Renew or extend" button.
   - Renewing before expiry extends from the current expiry date (not from today).

4. **Custom slug (Publish only)**
   - After upgrading, user can go to Edit Profile and change their slug.
   - `updateProfile` checks tier; free tier rejects slug changes.
   - Dashboard edit wizard preview step shows slug input only for Publish tier.

5. **Built with Peek badge**
   - `PortfolioPreview` accepts `showBadge?: boolean` prop.
   - Free tier: badge shown. Publish: badge hidden.
   - Public profile page (`[user.id]/page.tsx`) passes `showBadge={tier === "free"}`.

### Schema fields (`convex/schema.ts` profiles table)
- `tier: v.optional(v.union("free", "publish", "pro"))` — defaults to `"free"`
- `stripeCustomerId: v.optional(v.string())`
- `subscriptionExpiresAt: v.optional(v.number())` — Unix timestamp (ms) when access ends
- `viewCount: v.optional(v.number())`
- `phone: v.optional(v.string())`
- `showPhone: v.optional(v.boolean())`

### Environment variables (Convex dashboard)
- `STRIPE_SECRET_KEY`
- `STRIPE_WEBHOOK_SECRET`
- `SITE_URL`
- `JWT_PRIVATE_KEY`

### Stripe webhook events (register in Stripe dashboard)
- `checkout.session.completed` — only event needed (one-time payments)
